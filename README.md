# OAV ERP 庫存管理系統

PWA 架構的 ERP 庫存管理系統，涵蓋 SD 訂單 / MM 採購 / IM 庫存 / PP 生產四大模組。
核心原則：**能用 T-SQL 解決的業務邏輯，一律不寫在前端或後端 JS**——數量累加、參照完整性、
樞紐分析全部交給 SQL Server 的 trigger、constraint、view 與 table-valued function 完成。

## 功能模組

| 模組 | 組織架構 | 主數據 | 交易數據 | 報表輸出 |
|---|---|---|---|---|
| SD 訂單 | 銷售組織維護 | 客戶資料維護 | 客戶訂單／訂單出貨／出貨退回 | 已訂未出明細、訂單出退分析（樞紐） |
| MM 採購 | 採購組織維護 | 廠商資料維護 | 廠商採購／採購收貨／收貨退回 | 已採未交明細、採購收退分析（樞紐） |
| IM 庫存 | 工廠倉庫維護 | 物料資料維護 | 物料預留／庫存領用／庫存繳回 | 庫存異動明細、每日庫存餘額 |
| PP 生產 | 工廠代碼維護 | 物管資料維護、用量清單維護 | 生產工單／工單領料／工單入庫 | 庫存在途明細、每日供需餘額 |

每一張交易單據的主檔/明細，新增、修改、刪除都會由 SQL Server 觸發器即時把數量累加回上游單據
（例如出貨後訂單行的「已出貨數量」自動更新），刪除已被下游單據引用的資料會被資料庫的外鍵
約束擋下，不需要應用層額外檢查。

## 技術棧

- **前端**：純 HTML/CSS/JavaScript，無框架、無建置流程，PWA（manifest + service worker）
  離線時的新增/修改/刪除會先存進 IndexedDB 佇列，恢復連線後自動重送
- **後端**：Node.js + Express，三個設定檔驅動的通用引擎（主數據維護、單據主檔+明細維護、
  唯讀報表/樞紐分析），新增畫面只需改設定檔，不必手刻新路由或新前端元件
- **資料庫**：SQL Server，34 張資料表、4 個視圖、6 個過帳觸發器、14 個數量檢查約束、
  2 個樞紐分析 table-valued function

## 本機開發

```powershell
cd server
npm install
copy .env.example .env   # 填入實際的資料庫連線資訊
node server.js           # http://localhost:8080
```

資料庫結構變更後執行：

```powershell
powershell -File db/run_all.ps1
```
